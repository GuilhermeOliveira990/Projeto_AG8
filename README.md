# Pesquisa de Opinião - Desenvolvimento de Sistemas I

Este projeto foi desenvolvido como parte da disciplina **Desenvolvimento de Sistemas I**.  
O objetivo é criar um programa em Python que realize uma pesquisa de opinião sobre o atendimento ao cliente.

## 📋 Descrição da atividade
O programa coleta informações de 50 entrevistados, solicitando:
- Nome
- Idade
- Opinião sobre o atendimento:
  - 1: EXCELENTE
  - 2: BOM
  - 3: RUIM

Ao final, o programa exibe:
- Quantidade de respostas **EXCELENTE**
- Quantidade de respostas **BOM**
- Quantidade de respostas **RUIM**

## 📸 Prints
Os prints do código e da execução estão disponíveis na pasta `prints`.
